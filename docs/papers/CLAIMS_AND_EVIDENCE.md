# Claims and evidence ledger

This ledger is normative for public descriptions of the current artifact.

| Public statement | Status | Evidence | Qualification |
|---|---|---|---|
| Pete does not use an LLM | Supported | Runtime source and dependency audit | Applies to this standalone experiment |
| Pete loads no pretrained neural weights | Supported | No checkpoint path or neural runtime in the experiment | Fieldmap creates scalar relation weights online |
| Pete performs no offline task optimization | Supported | Clean runtime protocol and repository dependencies | It still learns during execution |
| Sudoku rules are absent from cognition | Supported subject to continuing boundary audit | Module boundary, import audit, tests | Rules remain authored inside the substrate world |
| Fieldmap forms task relations online | Supported | Initial/final state and interaction journals | Hypothesis space and update mechanics are authored |
| Pete discovers the Sudoku solving algorithm | Unsupported | Generic backtracking already exists in Sandbox | Do not claim |
| Pete autonomously discovers every representation | Unsupported | Coordinates, value domain, body channels, and scheduler are authored | Do not claim |
| Pete is task agnostic | Unsupported | Only the 9 x 9 Sudoku artifact is evaluated | Requires transfer experiments |
| Pete outperforms trained systems | Unsupported | No comparative benchmark | Do not claim |
| Pete has a measured success rate | Unsupported | One archived complete trace is not a population estimate | Report raw run evidence only |

## Required wording

Use:

> Pete begins without pretrained parameters or task knowledge in cognition. Interaction induces explicit, dynamically weighted relations in Fieldmap during execution. A generic authored Sandbox search uses those acquired relations, and the hidden-rule substrate verifies physical commitments.

Avoid:

- “zero prior knowledge”;
- “no hard-coded mechanisms”;
- “learned Sudoku from raw perception”;
- “discovered backtracking”;
- any accuracy or state-of-the-art statement until a preregistered multi-seed evaluation exists.
